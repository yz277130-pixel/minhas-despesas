Dados e segurança

Memória deste aparelho
Suas contas e parcelas ficam salvas no armazenamento do navegador deste celular. Use o backup para baixar uma cópia no aparelho e restaurá-la quando precisar.
Não precisa conectar Google Drive. O backup é um arquivo que você guarda no celular.

Adicionar despesa

Use esta opção para internet, celular, aluguel e outras contas que se repetem mensalmente.
Se parcelar, o valor total será dividido em parcelas mensais. Cada parcela entra automaticamente no mês certo e pode ser marcada como paga separadamente.

Importação e Backup

Fazer backup completo
Salva despesas, parcelas, contas fixas e configurações em um arquivo JSON que pode ser restaurado depois.
Importar / restaurar backup
Selecione um backup JSON criado pelo Minhas Despesas. Você poderá substituir os dados atuais ou juntar os registros sem duplicar IDs.
Exportar planilha
Gera um arquivo CSV que pode ser aberto no Excel, Google Planilhas ou LibreOffice.
Dica de segurança: mantenha uma cópia do backup fora do celular. Os dados continuam armazenados localmente neste aparelho; esta função não cria sincronização automática na nuvem.
